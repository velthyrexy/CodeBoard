# CodeBoard ⌨️

CodeBoard is a custom Android keyboard designed for developers, specifically built for Roblox & Luau programming. It operates completely offline with a modern black and yellow high-contrast theme.

## Features
- **Native Android IME:** Built using `InputMethodService` (works as a real system keyboard).
- **Exact 4 Code Suggestions:** Context-aware code completion for Luau & Roblox APIs.
- **100% Offline & Private:** Zero network calls, no data tracking, no internet permissions required.
- **High-Contrast Design:** Clean black and gold/yellow theme optimized for coding.

## Continuous Integration (GitHub Actions)
This repository automatically compiles a debug APK on every `push`. Download the compiled APK directly from the **Actions** tab of this repository.
